03 — How I work

Three things I hold to

The habits behind every app above.

001

Architecture before features

Clean Architecture, Cubit and clear layers from the first commit — so the second year of a project costs the same as the first.

002

Measured, not guessed

Every performance claim comes from DevTools on a real low-end device. 65% smaller payloads and 54% faster responses were numbers before they were sentences.

003

Shipped, not demoed

Store review, signing, kids-category compliance, TestFlight, staged rollout. A feature is done when a user can install it.
